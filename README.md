# Articles Library

A personal knowledge library built from video transcripts and web articles.

## Structure

```
raw/<author>/      — original transcripts and source texts
articles/<author>/ — full markdown articles
summary/<author>/  — condensed summaries (30–60 lines)
index.md           — catalog with dates, titles, and links
```
