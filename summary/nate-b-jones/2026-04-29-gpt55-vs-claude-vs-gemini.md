# Summary

[article](../../articles/nate-b-jones/2026-04-29-gpt55-vs-claude-vs-gemini.md)

GPT-5.5 evaluated through three stress tests designed to make frontier
models fail. Key thesis: the "floor" of capability moved — not just
incremental improvement but a shift in what you can ask a model to do.

## Key Findings

- *Dingo test* (executive work, 23 deliverables): 5.5 scored 87.3 vs
  Opus 4.7 at 67.0, Sonnet 4.7 at 65.0, Gemini 3.1 Pro at 49.8.
  Produced real artifacts (not fake file extensions). Understood legal
  posture and risk framing.

- *Splash Brothers* (465-file dirty data migration): First model to catch
  planted fake records (Mickey Mouse, $25K fake payment). Merged 7
  duplicate pairs, caught 13 name typos. But missed service code
  conflicts and some back-end hygiene (slight regression from 5.4).

- *Artemis II* (3D visualization): 5.5 stronger on information density;
  Opus 4.7 stronger on visual composition and taste. Neither perfect.

## Practical Routing

- Complex multi-step execution → 5.5
- Visual taste from blank canvas → Opus 4.7
- UI implementation → reference image + 5.5 in Codex
- Planning/architecture → Opus; execution → 5.5
- Data migrations → 5.5 with validation layer
- Writing structure → 5.5 (improved at holding long arguments)

## Key Insights

- "Can the model answer this?" → "Can the model carry this?"
- The model-plus-system (Codex + Images 2.0 + 5.5) is the real product
- Chat window use case is saturated; Codex is where work happens
- Availability is product quality: Anthropic at ~1 nine vs OpenAI 2-3
- Test models on hard tasks — easy tasks make differences invisible
- No model safe to trust blindly with production data
- Future of AI use is routing, not picking one model for everything

## Numbers

- OpenAI: 82% Terminal Bench, 84% GDP Val
- Top of Artificial Analysis intelligence index by 3 points
- Uses fewer tokens than 5.4 (smarter AND more efficient)
- Anthropic cut 10+ GW compute deals in 30 days for capacity
