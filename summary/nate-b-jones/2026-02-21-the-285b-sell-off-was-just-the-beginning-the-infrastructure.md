# The $285B Sell-Off Was Just the Beginning — Summary

The web is forking into a human web and an agent web. In a single
week, Coinbase launched Agentic Wallets, Cloudflare shipped Markdown
for Agents, and OpenAI published skills/shell tools — none coordinated,
all building toward the same autonomous agent infrastructure.

**Payments:** Coinbase's x402 protocol has processed 50M+ machine-to-
machine transactions. Stripe rebuilt its fraud detection from scratch
(human behavioral signals useless for agent buyers). Google, PayPal,
Visa, and others simultaneously launched agent payment protocols.

**Content:** Cloudflare (serving ~20% of the web) now serves markdown
to agents automatically, with companion features: llm.txt sitemaps,
AI Index (bypassing Google), and built-in x402 monetization.

**Search:** Exa.ai built agent-native search scoring 95% on Simple QA.
Latency matters — Brave returns in 669ms vs. 13.6s for Parallel Pro.

**Execution:** OpenAI shipped Skills (versioned instruction packages),
Shell (real Linux terminals for agents), and Compaction (context
management for long runs). Glean saw accuracy jump 73% to 85% with
one well-structured skill.

**Emergent web demo:** An OpenClaw agent took an Amazon link, crawled
the page, extracted assets, fed them to a video model, and produced
a UGC-style product video — zero human steps.

**Polymarket:** $12B volume in January 2026. Autonomous agents are
trading to subsidize their own token costs. Algorithmic traders
extracted ~$40M in arbitrage over 12 months. Reality check: requires
co-located infrastructure, significant capital, and $200+/day in
API fees.

**Security pattern:** Every serious approach treats the agent as a
potential adversary. IronClaw sandboxes tools in WebAssembly, OpenAI
uses container isolation, Coinbase uses enclave-isolated keys.

The analogy is the 2007 mobile web fork. Companies that recognized
the mobile fork early built the dominant platforms of the next era.
The agent fork is the same inflection — the new client isn't a smaller
screen, it's software that reads, decides, pays, and acts.

Central tension: infrastructure assumes full autonomy; humans prefer
70/30 control. The gap between what's being built and the trust people
will extend defines the next few years.
