# Apple Took Years to Catch Up, Kilo Code Took 6 Weeks — Summary

**Date:** 2026-01-24 16:00

**xAI Series E:** $20B round at $230B valuation. Colossus
supercomputers in Memphis with 1M+ H100 GPU equivalents. Grok 5 in
training. 600M MAU across X and Grok apps. Landed DoD AI agents
deal. Closed round despite regulatory probes in 5 countries over
deepfake generation. Three labs with clear runway: OpenAI, Anthropic,
xAI (plus Google via search revenue).

**Amodei vs. Hassabis at Davos ("The Day After AGI"):**
- Amodei: AGI in 2026-2027, AI writing its own code, Anthropic
  engineers rarely code by hand, entry-level jobs at risk
- Hassabis: 50% AGI probability by end of decade, getting 95% of a
  job increases value of the 5% that remain human, three AI gaps:
  memory, continuous learning, long-term reasoning
- Current evidence favors Hassabis view — aggregate employment data
  does not clearly show AI-driven disruption

**Apple-Google deal:** Multi-year collaboration, Apple foundation
models based on Gemini. ~$1B/year cost. Google building custom 1.2T
parameter Gemini model for Apple. Big loss for OpenAI — ChatGPT goes
from potential phone OS to secondary tier. Gemini becomes default AI
on both Android and iOS.

**DeepSeek Engram paper:** Conditional memory architecture. Uses hash
functions on short token sequences for fast embedding table lookup
instead of expensive multi-layer attention. Extremely token-efficient
factual memory retrieval — substantial performance gains with fewer
tokens.

**Kilo Code app builder:** Founded by GitLab co-founder, $8M seed.
Six-week sprint to launch. Five engineers, first demo in 3 days.
Targets engineers (not non-technical users like Lovable). Open-source,
GitLab playbook. Public roadmap that would be 12-18 months at most
companies = 5 more weeks for this team. Question: is there room
between Lovable, Cursor, Claude Code, and Codex?
