# Summary

Skills — markdown files encoding expertise — evolved from personal
config to cross-platform organizational infrastructure in six months.
Anthropic, OpenAI, and Microsoft all support the same format.

## Four Shifts Since October

1. **Personal → organizational** — admins roll out skills
   workplace-wide, version-controlled and callable across tools.
2. **Humans → agents as callers** — agents make hundreds of skill
   calls per run; skills must be agent-first.
3. **Developer → universal** — works for any domain (real estate GP
   built 50K+ lines across 50 repos for operations).
4. **Closed → open standard** — cross-platform, community-traded.

## Building Effective Skills

- Description is 80% of the work — must be specific, single-line,
  and "pushy" so agents trigger it confidently.
- Methodology needs: reasoning (not just steps), output format,
  explicit edge cases, examples, and brevity (100–150 lines max).
- Agent-first: description as routing signal, output as contract,
  composable for handoffs, scripts for deterministic behavior.
- Test skills quantitatively — run baskets of tests, version,
  re-test. Wording triggers different latent space regions.

## Three Team Tiers

1. **Standard** — org-wide (brand voice, formatting, templates).
2. **Methodology** — team craft (what takes new hires months to
   learn). Must move from senior heads into shared repos.
3. **Personal** — day-to-day workflows. Keep accessible, not just
   on your laptop.

## Key Insight

Skills compound through iteration and ecosystem investment. Prompts
evaporate after the session. A community skills repository
(OpenBrain) launches for domain-specific practitioner skills with
an agent readability bar.
