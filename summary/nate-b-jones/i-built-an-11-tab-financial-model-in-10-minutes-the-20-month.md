# I Built an 11-Tab Financial Model in 10 Minutes — Summary

Anthropic launched Claude as a native Excel sidebar add-in, opening
to all Pro tier users ($20/month) after enterprise beta. Built on
Opus 4.5 with full structural workbook awareness (every tab, formula,
cell reference). Norway's sovereign wealth fund saved an estimated
213,000 hours during beta.

**Demo:** 11-tab rent vs. buy model built in 10 minutes — summary
dashboard, sensitivity analysis (suggested by Claude), opportunity
cost vs. S&P 500, tax analysis with dynamic cross-tab references.
3-4 tab models build in single prompts; 8+ tabs need 1-2 handoffs.

**Data partnerships via MCP:** LSEG (live market data), Moody's
(credit ratings, 600M entities), S&P Capital IQ (financials),
FactSet, Morningstar (research), PitchBook (private company intel).
These give Claude capabilities generic models cannot match — pulling
live institutional data directly into Excel workflows.

**Six pre-built agent skills** productize junior analyst workflows:
DCF models, comparable company analysis, etc. Hours of drudgery
compressed into a prompt.

**Microsoft-Anthropic coopetition:** $30B partnership where Anthropic
buys Azure compute. Claude available in Copilot Studio and as
Microsoft 365 researcher agent. Microsoft simultaneously hosts,
competes with, and profits from Claude. Key product gap: Copilot
requires OneDrive/autosave; Claude works with local files — finance
teams prefer the latter.

**Strategic implications:**
1. Model providers and platforms are separating — Microsoft wins if
   any model provider wins (controls distribution)
2. Competition is now vertical integration (domain data + workflows),
   not horizontal model quality
3. "One AI to rule them all" thesis is dead — future is specialized
   AI per domain
4. Infrastructure providers win regardless of which model dominates

**Key insight:** The model race was Act One. Capabilities are
converging. Winners of the next phase will be whoever builds the
most durable industry relationships. Excel has 1B+ users. An AI
embedded there with institutional data connections is not a
chatbot — it is infrastructure. Available to anyone for $20/month.
