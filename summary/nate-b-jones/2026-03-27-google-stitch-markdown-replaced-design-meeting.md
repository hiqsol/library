# Summary

[article](../../articles/nate-b-jones/2026-03-27-google-stitch-markdown-replaced-design-meeting.md)

Three creative tool releases are shifting design to the command line:
Google Stitch, Remotion, and Blender MCP. All three use MCP as the
universal connector, making them accessible from any AI coding agent.

## Google Stitch

- Free tool (350 generations/month) — describe an app in words or
  voice, get high-fidelity UI screens (not wireframes)
- Holds full project context, allows branching/comparing design
  directions, auto-generates logical next screens
- Killer feature: design.markdown export — an agent-readable file
  capturing the full design system (colors, typography, spacing,
  components)
- Pipeline: describe objective → Stitch generates UI → coding agent
  reads design.markdown → builds directly. No Figma handoff
- Shipped with official Claude Code skills (notable: Google shipping
  skills for a competitor's tool)
- Honest take: not senior-designer-signoff quality yet, but better
  than prototyping and free

## Remotion

- React framework treating video as code, launched as Claude Code
  skill in January 2026
- 150,000+ installs on skills.sh, 6M+ views on demo in 48 hours
- Describe a video in English → Claude writes React components →
  renders to MP4 locally
- Not AI-generated video (like Sora/Runway) — it's programmable
  video: every element is a React component you can version control
  and parameterize
- Sweet spot: text animations, data visualizations, product demos,
  terminal recordings

## Blender MCP

- 17,000+ GitHub stars — natural language control over Blender's
  1,500 operators via Python API bridge
- Type a scene description, watch the 3D environment assemble in
  real time
- Integrates with Polyhaven, SketchFab, and Hyper 3D for assets
  and text-to-3D generation

## Key Insights

- MCP is the "USB plug for AI" — making your product an MCP server
  is the growth hack of 2026
- The 2010s product/engineering/design triangle is blurring — command
  line eliminates context loss and handoff overhead
- Combined with Claude's cloud scheduling, creative pipelines can
  run autonomously (weekly product videos, daily data visualizations,
  auto-updated marketing assets)
- The floor of creative work dropped to the basement (free), but the
  ceiling didn't move — excellence still matters
- Skill shifts from "can you execute" to "can you polish and
  articulate intent precisely"
- High-quality designers are more needed than ever for judgment and
  taste, not pixel-pushing
