# The OpenClaw Saga: Zuckerberg Begged This Developer — Summary

**Published:** 2026-02-17 15:00

Peter Steinberger, Austrian developer who sold his PDF company for
$100M+, joined OpenAI on Valentine's Day 2026. He built OpenClaw
(fastest-growing open-source project in GitHub history, 200K stars,
600 contributors, 10K+ commits in under 3 months) from his living
room while bleeding $20K/month.

Origin: Friday night hack in November 2025 — wired an LLM to
WhatsApp. Project 44 of 44 attempts. Named Claudebot, then Maltbot
(after Anthropic trademark notice), then OpenClaw. During renaming,
crypto scammers sniped the GitHub handle in seconds, launched a fake
$CLAW token on Solana that hit $16M market cap.

Both Zuckerberg and Altman competed for Steinberger. Zuck reached out
via WhatsApp, tried OpenClaw, gave blunt product feedback. Altman
offered compute (Stargate deal) and tokens. Deciding factor: mission
alignment — building an agent his mother could use — plus OpenAI's
agreement to keep OpenClaw open source through a foundation.

OpenAI did NOT acquire OpenClaw. Steinberger joined as employee;
OpenClaw moves to independent foundation (Chrome/Chromium model).
Three assets OpenAI gained: developer trust, architectural knowledge
(gateway, ClawHub marketplace, multi-model support), and community.

Security crisis shadowed the project: one-click RCE vulnerability,
21K+ exposed instances, 35K emails and 1.5M API tokens leaked from
Maltbook, 70% of ~4K skills mishandled secrets. Steinberger shipped
40+ security patches on Feb 12, two days before joining OpenAI.

Competitive context: Claude Code hit $1B ARR in 6 months. Codex
playing catch-up. Steinberger ran 4-10 agents simultaneously, made
6,600 commits in January alone, built most of OpenClaw by talking
to AI rather than typing.

OpenAI's direction: persistent consumer agent beyond ChatGPT — email,
calendar, messaging, file management. Steinberger says OpenClaw-style
agents will "kill 80% of apps." The hard problem is not model
capability but integration, persistence, and giving AI real access
to real systems.
