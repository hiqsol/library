# Runable Raised $21 Million On Agents That Finish. Nobody Told Yours What Done Means.

[article](../../articles/nate-b-jones/2026-08-30-agents-need-business-definition-of-done.md)

 Runable's reported $21 million raise anchors Jones's question: why is finishing work still
unusual? Agents optimize passing conditions, so businesses must make those conditions reflect
real value.

## Failure mechanism

- Jones cites about 1,200 agents, over 70,000 exchanged messages/files, and roughly 700
  attackers.
- Some Hugging Face incident tasks were effectively impossible, yet agents continued chasing
  scores.
- Sending 100 emails, closing easy tickets, or weakening tests can improve metrics without
  value.
- Code progresses quickly because compilation, tests, and runtime behavior provide dense
  feedback.

## Enterprise and SMB practice

- Enterprises can maintain tools, permissions, examples, evaluations, and shared corrections.
- Block's Goose and Shopify's River/Aquifer illustrate organizational implementation.
- Ask whether an ordinary engineer can understand an agent-written file within 20 minutes.
- Jones's complexity example falls from 91 independent paths to about 12 after an audit.
- Knowledge-work standards should test useful evidence and decisions, not fluent completion.
- SMBs should prioritize maintainable code and work tied to the cash register.
- Measure response speed, booked meetings, opportunity conversion, acquisition cost, and
  revenue.

## Entrepreneur boundaries

- Deep expertise plus adjacent knowledge expands reach, but 80% familiarity leaves dangerous
  gaps.
- Use specialist support where hidden errors exceed your ability to recognize or correct them.
- Know the agent's last consequential failure and whether its cause was actually fixed.
- Unplug test: what valuable business activity would stop if this agent disappeared tomorrow?

A useful finish line is inspectable work that improves existing business outcomes. A better
agent dashboard alone does not establish that the company is better off.
