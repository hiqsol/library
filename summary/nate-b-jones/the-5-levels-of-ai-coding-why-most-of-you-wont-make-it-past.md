# The 5 Levels of AI Coding — Summary

**Date:** 2026-02-18 15:01

Dan Shapiro's framework: Level 0 (spicy autocomplete), Level 1
(coding intern), Level 2 (junior developer), Level 3 (developer as
manager), Level 4 (developer as PM), Level 5 (dark factory). ~90% of
developers claiming AI-native are at Level 2. Almost nobody operates
at Level 5.

StrongDM's dark factory: 3 engineers, no human-written or reviewed
code. Agent reads markdown specs, writes code, tests against external
"scenarios" (holdout sets the agent cannot see). Digital twin universe
simulates Okta, Jira, Slack, etc. Output: 16K lines Rust, 9.5K Go,
700 TypeScript — shipped in production. Benchmark: $1,000/engineer/day
in token spend.

The paradox: METR RCT found experienced devs 19% slower with AI tools,
while believing they were 24% faster. The J-curve: productivity dips
before it surges. Most organizations are stuck at the bottom. The gap
between frontier teams and everyone else is accelerating.

Self-referential loop: Codex 5.3 helped build itself (25% speed
improvement, 93% fewer wasted tokens). 90% of Claude Code written by
Claude Code, converging toward 100%. 4% of public GitHub commits by
Claude Code, projected 20%+ by end of 2026. Claude Code: $1B run
rate in 6 months.

Organizational structures (standups, sprints, code review, QA) exist
because humans need coordination. When AI writes code, these become
friction. StrongDM has no sprints, no standups, no Jira. Bottleneck
moved from implementation speed to spec quality.

Brownfield reality: most enterprise software has no specification.
Migration path: (1) use AI at Level 2-3, expect J-curve, (2) use AI
to document what systems really do, (3) redesign CI/CD for AI code,
(4) shift new development to Level 4-5. Multi-month to multi-year.

Talent crisis: junior dev postings down 67% (US), graduate tech roles
down 46% (UK). Career ladder hollowed from underneath. Hiring shifting
toward generalists. Yet demand for excellent engineers is higher than
ever — bar is rising, not lowering.

AI-native orgs run 5-6x revenue per employee vs. SaaS average
(Cursor ~$3.5M, Midjourney ~$5M vs. SaaS ~$600K). The dark factory
amplifies great product thinkers — constraint moves from "can we
build it" to "should we build it."
