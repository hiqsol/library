# Summary: $690 Billion Is Squeezing AI Companies From Both Sides.

**Source:** Nate B. Jones, 2026-03-19
**Video:** https://www.youtube.com/watch?v=3FbqaD1MCUA

## Core Claim

Perplexity Computer is a great product sitting in a structural trap. The $690B/year cloud
infrastructure spend forces hyperscalers to own as many token-generating layers as possible.
Companies in the middleware layer — between model providers and customers — face a squeeze from
both directions simultaneously.

## The Stack

- Bottom: model providers own the weights
- Middle: orchestration/app layers combine models into products (Perplexity's position)
- Top: distribution owners control where users meet agents
- Above all: cloud providers with $690B/year capex they must fill with tokens

## The Squeeze

**From below:** Every upstream provider (Anthropic, OpenAI, Google) is building exactly what
middleware companies sell, and controls pricing and access.
**From above:** OpenAI Frontier launched as an enterprise context platform (semantic layer,
institutional knowledge, identity and permissions, evaluation loops) — the moat middle-layer
companies were counting on. Harvey, Sierra, Decagon, ABridge already signed as Frontier partners.

## Four Durable Middleware Positions

1. **Proprietary/fast-changing context** — structural context (system plumbing) is commodity;
   operational context is defensible if it updates faster than platforms can track; proprietary
   context (trading desk models, drug data, sensor data) won't be handed to platforms.
2. **Infrastructure agents call** — data feeds, domain APIs, verification services. Perplexity's
   search API is this. Quarter's earnings transcript API is the model. Not competing with
   hyperscalers; serving them.
3. **Deep workflow integration** — the question isn't which model you use, it's how many
   institutional workflows break if someone rips you out. Switching costs are real when agents
   encode institutional knowledge over time.
4. **Trust and verification layer** — three incompatible trust architectures (local/OpenClaw,
   cloud/Perplexity, OS-level/Google) deployed simultaneously. Someone needs to audit, verify,
   enforce policy. Model providers are focused on capabilities. The gap is a building opportunity.

## Three Dead Ends

- Fighting over which cloud runs tokens (zero sum, hyperscalers will win)
- Margin without differentiation (token volume grows but middleware margin compresses to zero)
- Competing for the enterprise relationship hyperscalers are already locking in

## Key Insight

Perplexity's strategic exit from the middleware trap is the search API — agent infrastructure —
not Computer. That got less press. The decision to kill advertising confirms leadership understands
the structural game. For everyone else: find the position where hyperscaler incentives align with
your existence rather than your replacement. The window is narrowing with every capability jump.
